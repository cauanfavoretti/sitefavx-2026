# sitefavx-2026

Landing page da FAVX, desenvolvida com Next.js, React e TypeScript.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000 no navegador.

## Comandos

- `npm run dev`: inicia o servidor de desenvolvimento.
- `npm run build`: gera a versão de produção.
- `npm start`: inicia a versão de produção.
- `npm run lint`: verifica o código com ESLint.

## Estrutura

- `src/app`: página principal, estilos globais, privacidade e termos.
- `src/components`: seções, carrossel de clientes e efeitos interativos da hero.
- `public/clients`: imagens e logos dos clientes.
